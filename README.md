# Santhosh Portfolio

A responsive portfolio built with React, Vite, Bootstrap 5, JavaScript and custom CSS.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder.
3. Open the folder in VS Code.
4. Open the terminal in this folder and run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite (usually http://localhost:5173).

## Before publishing

Update these placeholders in `src/App.jsx`:
- `your.email@example.com` (replace both occurrences with your email)
- LinkedIn profile URL
- GitHub profile URL
- Project links and descriptions, if needed

## Build for hosting

```bash
npm run build
```

Upload the generated `dist` folder to your hosting provider.
